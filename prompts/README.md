# Oturum talimatlarının kökeni

`session1_reverse_engineer.md` ve `session2_cleanroom_implementation.md` önceki çalışmadan kalan **taslaklardır**; tarihsel ilk prompt kaydı olarak sunulmaz. Özellikle taslaktaki LEDGER erişimi, güncel temiz oda sürecinin izin listesi değildir.

İlk inceleme oturumunun orijinal ilk prompt'u ham konuşma dışa aktarımı olmadan doğrulanamadı. Eksik bir geçmiş kaydı sonradan yazıp gerçek ilk prompt diye adlandırmıyoruz.

Teslim denetiminde başlatılan yalnız-SPEC oturumunun gerçek başlangıç talimatı `spec-only/FIRST_PROMPT.md` içinde tutulur. İzin listesi ve SPEC özeti `evidence/spec-only-handoff.json` içindedir. Bu oturum önceki geliştirme tarihini değiştirmez; ayrı bir yeniden yazımdır.
