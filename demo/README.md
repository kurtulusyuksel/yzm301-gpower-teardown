# 60 saniyelik CLI demosu

[Videoyu indir / aç](cli-demo.mp4). GitHub önizlemesi açılmazsa **View raw / Download raw file** seçeneğini kullanın.

Video, gerçek CLI alt süreçlerinin stdout/stderr ve çıkış kodlarıyla oluşturulan terminal kaydının görselleştirilmesidir; masaüstü ekran çekimi değildir. Çıktılar elle yazılmamıştır. Gösterim araları betikle zamanlanır. Ses içermez.

- [cli.cast](cli.cast): zaman damgalı asciicast v2 kaydı.
- [commands.json](commands.json): gerçek komutlar, çıktılar, süreler ve çıkış kodları.
- `node scripts/demo.mjs`: kaydı yeniden üretir (60 saniye).
- `python scripts/render-demo.py`: Pillow ve FFmpeg ile MP4 üretir.

Örnekler kurgusaldır: çift yönlü a-priori N=54, N=54 post-hoc güç, bağımsız temiz oda CLI'si ve geçersiz post-hoc N=2.
